# Backend Edge Functions

This directory contains edge functions for the D&D application.

## Character Edge Function

The `character.ts` file is a **Supabase Deno Edge Function** that handles character creation and updates with `character_options` stored as JSON.

### Setup

1. Install dependencies (if using locally):
```bash
npm install
```

2. Set up environment variables in Supabase:
   - `SUPABASE_URL` - Your Supabase project URL
   - `SUPABASE_SERVICE_ROLE_KEY` - Your Supabase service role key (for bypassing RLS)

### Database Schema

Make sure you have a `characters` table in your Supabase database:

```sql
CREATE TABLE characters (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL,
  character_options JSONB NOT NULL DEFAULT '{}',
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- Add indexes
CREATE INDEX idx_characters_user_id ON characters(user_id);
CREATE INDEX idx_characters_created_at ON characters(created_at);

-- Optional: Add RLS policies
ALTER TABLE characters ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Users can view their own characters"
  ON characters FOR SELECT
  USING (auth.uid() = user_id);

CREATE POLICY "Users can insert their own characters"
  ON characters FOR INSERT
  WITH CHECK (auth.uid() = user_id);

CREATE POLICY "Users can update their own characters"
  ON characters FOR UPDATE
  USING (auth.uid() = user_id);
```

### Usage

#### Create Character (POST)

**Note:** `character_id` is auto-generated by the database, don't include it in the request.

```json
{
  "user_id": "user-uuid-here",
  "character_options": {
    "name": "Aragorn",
    "level": 5,
    "class": "Ranger",
    "race": "Human",
    "stats": {
      "hp": 45,
      "mp": 20,
      "str": 16,
      "dex": 14,
      "int": 12
    }
  }
}
```

Or with flat structure:
```json
{
  "user_id": "user-uuid-here",
  "name": "Aragorn",
  "level": 5,
  "class": "Ranger"
}
```

#### Update Character (PUT/PATCH)

**Note:** `character_id` is **required** for update requests.

```json
{
  "user_id": "user-uuid-here",
  "character_id": "character-uuid-here",
  "character_options": {
    "name": "Aragorn Updated",
    "level": 6,
    "stats": {
      "hp": 50
    }
  }
}
```

### Character Options Transformation

The function automatically normalizes character options:

- **name**: Converts to string, defaults to "Unnamed" if missing
- **level/lvl**: Converts string numbers to integers, supports both `level` and `lvl` keys
- **stats**: Ensures object structure with numeric values (hp, mp, str, dex, int)
- **Removes**: `_temp` and `clientOnly` fields

### Response

#### Success - Create (201):
```json
{
  "message": "Character created",
  "character": {
    "id": "uuid",
    "user_id": "uuid",
    "character_options": { ... },
    "created_at": "2024-01-01T00:00:00.000Z",
    "updated_at": "2024-01-01T00:00:00.000Z"
  }
}
```

#### Success - Update (200):
```json
{
  "message": "Character updated",
  "character": { ... }
}
```

#### Error (400/404/500):
```json
{
  "error": "Error message",
  "details": "Additional error details"
}
```

### Deployment

#### Supabase Edge Functions

1. Install Supabase CLI:
```bash
npm install -g supabase
```

2. Login to Supabase:
```bash
supabase login
```

3. Link your project:
```bash
supabase link --project-ref your-project-ref
```

4. Deploy the function:
```bash
supabase functions deploy character --no-verify-jwt
```

Or place the function in your Supabase project structure:
- Create `supabase/functions/character/index.ts`
- Copy the function code there
- Deploy using Supabase CLI

### Environment Variables

Set in Supabase Dashboard → Project Settings → Edge Functions:
- `SUPABASE_URL` (automatically available)
- `SUPABASE_SERVICE_ROLE_KEY` (set manually for service role access)
